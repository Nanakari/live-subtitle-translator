# Security Policy

## Reporting a vulnerability

Do not disclose API keys, captured audio, transcripts, logs, local configuration, or vulnerability details in a public issue.

Use GitHub Security Advisories for private reports when available. Otherwise, contact the repository owner through the GitHub profile and share only enough information to establish a private channel.

If a credential may have been exposed, revoke it in the provider console immediately and create a replacement.

## Local data

`config.local.yaml`, `.env`, logs, audio captures, and virtual environments are excluded from version control. Review screenshots and diagnostic output before sharing them because subtitle text and page information may be sensitive.
