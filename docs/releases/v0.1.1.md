Windows x64 便携版补丁更新，修复流式字幕中小数被错误分句的问题。

## 修复

- Gemini 将小数分成 `3.` 和 `14` 等多个文本片段发送时，字幕现在保留待确认的小数点，显示为 `3.14`。
- 原文、译文和双语模式，以及 Classic 和 Compact 布局均覆盖此修复。
- 真正以整数结尾的句子仍可在后续空格、回合结束或已有稳定超时后提交；普通句末和已识别的缩写保持原有行为。

## 下载与升级

下载 `LiveSubtitleTranslator-v0.1.1-windows-x64.zip` 并完整解压，再运行 `LiveSubtitleTranslator.exe`。无需安装 Python。建议解压到新的目录，保留旧版本；需要沿用配置时，仅将自己的 `config.local.yaml` 和可选的 `desktop_state.json` 复制到新目录。

新安装可将程序旁的 `config.local.example.yaml` 复制为 `config.local.yaml` 并填写自己的 Gemini API key，也可通过 `GEMINI_API_KEY` 环境变量提供密钥。支持 Windows 10/11 x64，需要立体声播放设备、网络和可使用所配置 Live 模型的 Gemini API key。系统播放音频会发送至 Gemini，API 使用可能产生费用。程序未签名。

- 便携版构建必须通过实际可执行文件的离线烟雾测试，验证默认配置、运行依赖、合成音频转换、Gemini 配置构建及隐藏 Tk 窗口的双语渲染和布局切换。
- 离线检查不调用真实 Gemini API，不采集播放音频，不代表已完成真实网络或声卡联调。
